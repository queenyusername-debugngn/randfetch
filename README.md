# randfetch

A randomized Linux terminal fetch and ASCII art generator.

Every time you run `randfetch`, it randomly generates a terminal display with different greetings, colors, layouts, and visual patterns.

## Features

- Randomized terminal greetings
- ANSI colors and text styles
- Multiple display layouts
- Random ASCII art and glitch patterns
- Lightweight Bash script

## Requirements

- Linux or another Unix-like environment
- Bash

## Installation

Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/randfetch.git
cd randfetch
chmod +x randfetch
```

Run it:

```bash
./randfetch
```

Replace `YOUR-USERNAME` with your GitHub username.
